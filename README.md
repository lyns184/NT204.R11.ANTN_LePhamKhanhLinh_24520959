# Packet Capture & Parser cho hệ thống IDS

## Mục tiêu

Xây dựng module thu thập và phân tích gói tin cho hệ thống IDS bằng Python.

Chương trình dự kiến hỗ trợ:

- Đọc packet từ file PCAP.
- Bắt packet trực tiếp từ network interface.
- Phân tích IPv4, TCP, UDP, HTTP/1.x, DNS và SMTP.
- Chuẩn hóa kết quả và lưu dưới định dạng JSON Lines.

## Công nghệ

- Python
- Scapy

## Khai báo sử dụng AI

- Công cụ: ChatGPT.
- Mục đích: giải thích yêu cầu, gợi ý cấu trúc chương trình và hỗ trợ tìm lỗi.
